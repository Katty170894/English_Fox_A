# English Fox 0.5.0 — обновлённый интерфейс

Сохранены 42 миссии и совместимость с прогрессом предыдущей версии.

## Изменения по референсу

1. Стартовый экран с авторской иллюстрацией лисёнка и кнопкой Start Adventure.
2. Создание и редактирование локального профиля: имя, точный возраст 5–9 лет, 4 аватара. Данные сохраняются на устройстве, регистрация на сервере не требуется.
3. Все 148 уникальных слов имеют офлайн-картинки: иллюстрации животных и еды, изображения предметов, наглядные схемы чисел, цветов, форм и пространственных отношений. Значения orange как цвета и фрукта разделены контекстом миссии.
4. Нижнее меню Map / Lessons / Shop / Profile. Иллюстрированная карта 6 миров; заблокированные уроки; магазин аксессуаров за игровые монеты; профиль с прогрессом и активностью за последние 7 дней.
5. Отдельный экран Great job с процентом правильных ответов и фактически полученными звёздами/монетами. При повторном прохождении награда равна нулю.
6. Новая Android-иконка с лисёнком, включая adaptive icon.

Урок состоит из знакомства с картинками и озвучкой, затем выбора правильного ответа. Произнесение слова ребёнком не записывается и автоматически не оценивается. Денежных покупок и серверной учётной записи нет.

## Проверки

- Проверка наличия изображений для всех слов.
- Сохранение старого прогресса при создании профиля, начисление наград, покупка и повторное надевание аксессуара.
- Создание профиля, валидация имени, возраст, аватар, повторный запуск.
- Прохождение урока, экран Great job, открытие следующей миссии.
- Экран 320×640: форма профиля и магазин.
- Горизонтальный стартовый экран 640×360.

Все 6 автоматических тестов прошли. Скриншоты интерфейса получены из Flutter widget-тестов. Физический Android-телефон и эмулятор не использовались; TTS в тестах имитируется платформенным каналом.

## Иллюстрации и лицензии

Шесть графических ресурсов сгенерированы встроенным image_gen: welcome-fox.png, animals-atlas.png, food-atlas.png, adventure-map.png, great-job.png, app-icon.png. Полные промпты сохранены в IMAGE_ASSETS.md.

Дополнительные PNG: Google Noto Emoji, https://github.com/googlefonts/noto-emoji (2D/png/128). Сведения об источнике и лицензии включены в assets/words/.
Шрифт Nunito: Google Fonts, SIL Open Font License; лицензия включена в assets/fonts/OFL.txt.

## Сборка

Flutter 3.47.5, Android SDK 36, NDK 28.2.13676358. В Windows используйте физический путь к сборочной папке без кириллицы.

```powershell
flutter pub get
dart run flutter_launcher_icons
flutter analyze
flutter test
flutter build apk --release
```

APK подписывается стандартным Android Debug-ключом для установки и тестирования. Для публикации в магазине необходим собственный release-ключ.
